### 👋 Hey there

- 🏭 By day I own the web platform for ZURU's Manufacturing Execution System, the real-time app that runs the lines in 3+ robotic factories
- 🎨 I built **Aurora**, ZURU's design system: 60+ React components and 400+ icons that every ZURU web app uses
- ⚡ I moved the live factory app onto Aurora with zero downtime and cut load time by 50% and bundle size by 80%
- 🤖 I drew a live map of the factory's robot vehicles (AGVs) on the raw Canvas API
- 🌱 Joined ZURU as an intern in 2022, now a Senior Software Engineer mentoring 3 engineers
- 💬 Ask me anything: [open an issue](https://github.com/SujalXplores/SujalXplores/issues)
